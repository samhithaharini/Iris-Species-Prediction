## **Iris Species Prediction — Logistic Regression**

A simple yet powerful Machine Learning classification project that predicts the species of iris flowers (Setosa, Versicolor, Virginica) using Logistic Regression.

---

**Project Overview**

This project uses the famous Iris dataset from sklearn to build a ML model that predicts the flower species based on:

-Sepal Length

-Sepal Width

-Petal Length

-Petal Width

Logistic Regression is used because it is lightweight, interpretable, and works well for multiclass classification.

---

**Dataset**

The dataset contains 150 samples and 4 features, divided into 3 classes:

Species	Count

Iris-setosa	50

Iris-versicolor	50

Iris-virginica	50


🧠 Machine Learning Workflow

Load dataset

Convert to pandas DataFrame

Perform train-test split

Train Logistic Regression model

Predict species

Evaluate accuracy

🔢 Model Used

Logistic Regression (Multinomial)

Fast training

High accuracy

Good for linearly separable classes
